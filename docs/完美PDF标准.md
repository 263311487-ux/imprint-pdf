# Imprint · 完美 PDF 标准（质量契约 v1）

> 一句话定义：**完美的 PDF = 读者打开的那一刻，觉得这是出版社排出来的，而不是程序生成的。**
> 本文件是 Imprint 的"完美"定义与验收标准。每个生成的 PDF 都要按此标准自检打分。

## 一、视觉正确（排版不出错）
- [ ] 中文正文宋体、标题黑体，中英文混排间距自然（1/4 em）
- [ ] 首行缩进 2 字符
- [ ] 标点避头尾（句号/逗号不出现在行首）
- [ ] 无孤行寡行（段落末行不孤悬、标题不孤悬页尾）
- [ ] 数字、英文、代码字体正确回退

## 二、内容层次（信息可读）
- [ ] 标题层级一眼可辨（H1/H2/H3 视觉差异明显）
- [ ] 目录页码精确、可点击跳转
- [ ] 表格跨页重复表头、单元格内边距合适
- [ ] 代码块不跨页截断、语法高亮清晰
- [ ] 图片自适应版心、不溢出、带图注
- [ ] 页眉页脚（书名/章节/页码）专业

## 三、工程可靠（PDF 内在质量）
- [ ] 文本可选、可搜索（不是图片 PDF）
- [ ] 字体子集嵌入、文件体积合理
- [ ] 元数据完整（标题/作者/关键字）
- [ ] 同一输入 → 同一输出（可复现）

## 四、体验流畅（使用者感受）
- [ ] 一行命令完成（imprint in.md -o out.pdf）
- [ ] 任意 Markdown 容错渲染（烂输入不报错）
- [ ] 大文档不慢、不卡

## 五、审美气质（品味与设计感）★ 差异化核心
- [ ] 配色系统：主色/辅色/层级色，而非默认黑
- [ ] 留白呼吸感：版心、段距、行距有疏密节奏
- [ ] 比例协调：版心黄金分割、标题/正文字号比例（2:1.5:1）
- [ ] 细节质感：标题细线、页码样式、引用左竖线、章节首页处理
- [ ] 风格一致性：全书一种气质，不混搭
- [ ] 主题即设计系统：每套主题 = 字体配对 + 色板 + 间距 tokens + 装饰细节

## 六、验证可证（完美可证明）★ 差异化核心
- [ ] 每个 PDF 自带「印刷级质检报告」：0-100 分 + 检查证据
- [ ] 自动检查：文本可选性 / 字体嵌入 / 避头尾违规数 / 孤行数 / 表格跨页 / 元数据完整性 / 审美一致性
- [ ] 分数可对比（同一文档，不同工具生成的 PDF 放一起打分）

## 验收门槛
- 默认主题输出的示例文档，印刷级评分 ≥ 90 分才能发布
- "打开第一眼像出版社排的，不是程序生成的" —— 用户主观验收（盲测对比）

## 主题规划（每个都是一位"设计师的作品"）
| 主题 | 气质 | 色板 | 字体 |
|---|---|---|---|
| modern | 现代杂志 | 深灰+靛蓝点缀 | 苹方/黑体+宋体正文 |
| academic | 学术书卷 | 沉静靛蓝+米白 | 宋体+楷体引用 |
| minimal | 极简留白 | 黑白+一线金 | 黑体+细宋 |
| ink | 复古线装书 | 墨色+朱砂点缀 | 楷体+宋体 |
